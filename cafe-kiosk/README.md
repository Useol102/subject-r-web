# 카페 주문 키오스크 (1차 · 프런트엔드만)

교육용 카페 주문 키오스크 웹 1차 결과물이다. 화면 5개(시작 → 메뉴 선택 → 주문 확인 → 결제 방식 선택 → 주문 완료)를 **프런트엔드만으로** 구현했다.
실제 결제·데이터베이스·백엔드 연동은 없다. 메뉴는 `src/menu.ts` 상수이고, 결제는 2초 뒤 완료되는 흉내다.

> 이 폴더는 같은 저장소의 복지관 키오스크(`web/`, `web_api/`)와 **무관한 별도 앱**이다. 서로 코드를 공유하지 않는다.

## 실행

```powershell
Set-Location cafe-kiosk
npm install
npm run dev
```

`http://127.0.0.1:5174/` 를 연다. (복지관 화면 `5173` 과 겹치지 않게 포트를 다르게 뒀다.)

빌드·테스트:

```powershell
npm test          # 장바구니·금액 계산 테스트 (vitest)
npm run build     # tsc 타입 검사 + vite 빌드 → dist/
```

`dist/index.html` 은 상대 경로로 빌드되어 파일을 더블클릭해 열어도 동작한다.

## 구조 원칙

- **금액·장바구니 계산은 `src/cart.ts` 의 순수 함수**에만 둔다. 화면 코드에 계산을 넣지 않는다. 바꾸면 `src/cart.test.ts` 를 같이 고친다.
- 메뉴 데이터는 `src/menu.ts`. 나중에 서버가 생기면 이 파일만 API 응답으로 바꾼다.
- 외부 CDN·글꼴·이미지 없음. 그림은 이모지로 대신한다(설치 후 오프라인에서도 돈다).
- 터치 대상은 56px 이상. 360 ~ 1366px 폭과 세로 키오스크(1080×1920)에서 가로 스크롤 없음을 확인했다.
