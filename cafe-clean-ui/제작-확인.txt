카페 주문 키오스크 1차 제작 확인

요구 범위: 시작, 메뉴 선택, 주문 확인, 결제 방식 선택, 주문 완료 5개 화면.
기본 동작: 메뉴 선택, 온도/크기 옵션, 수량 변경, 금액 계산, 삭제, 화면 이동, 결제 연습, 처음 화면으로 돌아가기.
외부 연동: 실제 결제, 서버, DB 없이 프론트엔드만 사용.

디자인: 큰 글씨·버튼, 현재 단계 표시, 다음 행동을 강조한 파란 버튼, 화이트/라이트그레이 배경. SubJectR 문구·로봇 캐릭터 없음.
글꼴: 애플 기기에서는 시스템 글꼴, Windows에서는 포함된 Pretendard 사용. SF Pro 파일 자체를 배포한 것은 아님.
모션: 짧은 화면/팝업 전환, 버튼 눌림 피드백. 동작 줄이기 설정 지원.

검수 환경: Windows Chrome 실제 브라우저. 화면 폭 360/390/600/768/900/1024/1366px와 시작·메뉴·옵션·주문 확인·결제·완료 화면 조합.
확인 항목: 수량 변경 시 9,000원→4,500원 계산, 결제 후 금액 일치, JavaScript 오류, 페이지 가로 넘침, 팝업 키보드 포커스, Esc 취소, 동작 줄이기, 로컬 글꼴 로드, 원본 주문 번들 동일성.
실제 교육용 터치 장비에서는 화면 배율과 터치 반응을 추가 확인해 주세요.

소스: 새 HTML/CSS/JavaScript UI 소스와 첨부본의 기존 React 빌드 번들 포함. 원본 React/TypeScript 프로젝트는 첨부 ZIP에 없었음.
GitHub: 미인증 상태라 원격 업로드는 아직 하지 않았음. 제공 폴더 전체를 업로드 가능.
