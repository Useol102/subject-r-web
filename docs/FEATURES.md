## 이 표의 사용법

기능을 추가하거나 화면이 바뀌면 **여기부터 고친다.**
그다음 `상태`가 ❌ 인 줄을 보고 스키마·API를 만든다.

거꾸로, API를 새로 만들 때는 **어느 기능 ID를 위한 것인지** 커밋 메시지에 적는다.

```
feat(S-09): POI 편집 API 추가
```

이러면 "이 API 왜 있지?" 를 나중에 추적할 수 있다.
1차 때 이게 없어서 요구분석과 대조가 안 됐다.
